# Scripts

![2](https://github.com/user-attachments/assets/b01f8369-a54c-4ca4-b832-6acee2dbb87e)


A well-organized collection of shell scripts for automating developer setups, system configurations, and environment-specific tasks. These scripts are grouped by application or environment and are designed to save time, reduce setup friction, and improve repeatability in development workflows. Please refer [here](https://rohanbatrain.github.io/knowledge-base/) if you were looking for my developement setup.

---

## 📁 Categories

- **Database**
  - MongoDB installation (Debian-based)
- **Git**
  - Git initial setup
- **GitHub**
  - Clone all repos from a user/org
  - Get creation dates of all repos
- **Package Managers (Aptitude)**
  - Switch to fastest mirrors
  - Install tools like VSCodium
- **Termux**
  - SSH setup
  - Full Termux initialization script

---

## 🚀 Getting Started

1. Clone this repo:
   ```bash
   git clone https://github.com/yourusername/scripts.git
   cd scripts
   ```

2. Browse into a script category, review the script, and run:
   ```bash
   cd Application-Specific/Github
   bash Repo-Clone.sh
   ```

💡 **Note:** Some scripts may require elevated privileges (`sudo`) or tools like `jq` depending on what they're automating.
